# Belanja Keluarga Halimah

Aplikasi web untuk menjejak perbelanjaan harian dan bulanan Ibu Halimah, Raihani dan Rufaida.

- Rekod perbelanjaan dengan **suara** (Bahasa Melayu, contoh: "makanan 12 ringgit 50 nasi lemak untuk Raihani") atau **taip**
- Kategori sedia ada (Makanan, Barang Dapur, Susu & Lampin, Pendidikan, dll.) serta kategori sendiri
- Dashboard: hari ini, minggu ini, bulan ini, baki bajet, carta harian, rumusan mingguan, carta kategori, ikut ahli keluarga
- Eksport CSV; data disimpan dalam peranti (localStorage); boleh dipasang ke skrin utama (PWA)

Buka `index.html` atau hoskan dengan GitHub Pages (Settings → Pages → branch ini).
